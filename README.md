# NUCALORIC website

Live: https://lukeyarosz-cell.github.io/nucaloric-site/

Public website preview published with GitHub Pages. The continuous creator dashboard includes local AI, terminal, server tools, wallet connections, credits, creator-owned GitHub connections and X Money payout plans.

Wallet Standard supports Phantom, Solflare, Jupiter Wallet, Brave Wallet and Backpack; installed wallets require user approval. The Pi-hosted account backend verifies wallet ownership and manages private workspaces. GitHub Pages is a frontend preview: account, AI, container, credit and provider execution endpoints run on the Pis.

Company GitHub App credentials and HTTPS origin, a Jupiter key, a reviewed treasury and credit prices, and Tailscale enrollment are required for the gated integrations. Current Free hosting stays free. X Money payout plans do not move funds; automatic transfers require official provider integration access.

Provider setup and execution limits are documented in [Creator integrations](docs/CREATOR_INTEGRATIONS.md). Public source contains no credentials or private backend state.
