# NUCALORIC website

Live: https://lukeyarosz-cell.github.io/nucaloric-site/

Make something real. The website brings Project Studio, local intelligence, Pi workspaces, and Solana discovery into one connected experience. The Make It Real campaign refresh adds an idea entry, an interactive product walkthrough, the approved brand film, and the film’s typography, light and white-to-blue finish across the site.

Wallet Standard supports Phantom, Solflare, Jupiter Wallet, Brave Wallet and Backpack; installed wallets require user approval. The Pi-hosted account backend verifies wallet ownership and manages private workspaces. GitHub Pages is a frontend preview: account, AI, container, credit and provider execution endpoints run on the Pis.

Basic servers cost $1.50 per prepaid calendar month; Full workspaces cost $2. Own-hardware planning is free. Tiny and Small use a shared free allowance; Reason and Code cost $0.50 per 1,000 processed input and output tokens. X Money payout plans do not move funds; automatic transfers require official provider integration access.

Provider setup and execution limits are documented in [Creator integrations](docs/CREATOR_INTEGRATIONS.md). Public source contains no credentials or private backend state.

Design changes and browser verification: [Make It Real refresh](docs/CAMPAIGN_REFRESH.md). Add `?preview=1` to the GitHub Pages URL to review the public frontend without a gateway redirect.
