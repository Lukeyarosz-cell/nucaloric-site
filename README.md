# NUCALORIC website

Live: https://lukeyarosz-cell.github.io/nucaloric-site/

Public website source, published with GitHub Pages.

Working features: read-only Solana pool search and pool details via DEX Screener; saved pool watchlists; direct-browser official provider status checks; a multi-project local library, milestone checklists, recoverable archiving, and portable JSON backups.

Projects and watchlists are stored in the current browser. Export/import project backups to move work between devices. Backend wallet connections, token launches, Paymenter purchases, workspace provisioning, AI execution, and X payments remain unconfigured.

[DEX Screener API documentation](https://docs.dexscreener.com/api/reference).
