# Campaign media

Rendered from the approved NUCALORIC Make It Real v20 film project. `rose-loop.mp4` and `pearl-loop.mp4` use the same motion plates and lighting shader as the film; the matching WebP files provide still and reduced-motion fallbacks. `make-it-real.mp4` is the web-compressed approved film. It is fetched only when a visitor chooses Watch the film.

Instrument Sans is licensed under the SIL Open Font License, included in `OFL.txt`. Brand lettering uses the existing vector in `assets/nucaloric-wordmark.svg`. No new third-party runtime scripts are loaded.
