BEFORE YOU START

A few useful answers.

Which models are free?+

Tiny and Small use the free shared allowance. Reasoning and Code cost $0.50 per 1,000 high AI credits. One credit covers one processed input/context or output token, including reasoning. Unused reservations and failed requests are refunded. Basic and Full include a shared website slot, 32 MB RAM and 0.25 CPU.

Do I need a card?+

Connect a Solana, Ethereum, Robinhood Chain or Bitcoin wallet and approve each purchase. Network fees are separate. Basic costs $1.50/month and Full costs $2/month. Renew manually with server credits; no automatic wallet charge.

Can I run a model on a Raspberry Pi?+

Use the planner to check the workload against your machine. Model size, available memory and ARM compatibility determine what is suitable. There is no model-capacity guarantee.

Can I stop or remove a server?+

Yes. Manage the server from Services or Billing. Stopping keeps its slot reserved. Removing frees its slot, and cancelling its enrollment also removes the server.
