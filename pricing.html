BEFORE YOU START

A few useful answers.

What does the free option include?+

Website hosting includes one static website container, 32 MB RAM and 0.25 CPU. Publish an HTML page and use its command line from your account. Five slots are shared across the Pi. Own-hardware planning includes exports; you provide the machine.

Do I need a card?+

No. The website server uses a Free plan with no setup fee or renewal charge. Payment collection is not enabled.

Can I run a model on a Raspberry Pi?+

Use the planner to check the workload against your machine. Model size, available memory and ARM compatibility determine what is suitable. There is no model-capacity guarantee.

Can I stop or remove a server?+

Yes. Manage the server from Services or Billing. Stopping keeps its slot reserved. Removing frees its slot, and cancelling its enrollment also removes the server.
