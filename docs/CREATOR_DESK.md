# Creator desk

The dashboard uses a continuous four-column layout inspired by the supplied workspace reference: a narrow shortcut rail, a searchable work list, an AI and terminal canvas, and a details inspector. Existing NUCALORIC fonts, artwork, wallet icons and dark/pink palette remain in use. Surfaces use flat colors.

Projects, servers and coins change the work list without replacing the AI or terminal. Project selection preserves both transcripts. The project inspector edits the brief, adds milestones, tracks completion and archives projects. The Archived filter restores a project. Projects and milestones are saved in browser storage on this device; Export and Import use the existing validated backup format. They are separate from authenticated server and coin records.

Server and coin lists contain the signed-in account’s native records. Selecting a server uses the existing owner-checked terminal. Selecting a coin uses its existing private AI workspace, models, saved context and knowledge. The inspector preserves the authentication gate for private coin controls. Connections, payout plans, credits, Jupiter tools, fleet status and the selected server plan remain available as expandable inspector modules.

Ctrl/Command K opens the searchable action palette. Arrow keys select an action, Enter opens it, and Escape closes it. Outside text fields, / searches the library. Alt 1 opens the terminal, Alt 2 focuses AI, and Alt 3 opens the project list. Panel arrow buttons give AI or terminal more room while leaving the other tool visible.

Panels arrive once with subtle motion; selections and disclosures provide short feedback. Motion can be paused, and the operating system’s reduced-motion preference is respected. Other pages use shared panel surfaces, focus states and one-shot module arrivals. Animation code uses observers and browser animations rather than continuous timers.

At desktop widths the desk fits the available screen, with independent list, conversation, terminal and inspector scrolling. Tablet and phone layouts stack the same modules without introducing pages or tabs that hide the working tools.
