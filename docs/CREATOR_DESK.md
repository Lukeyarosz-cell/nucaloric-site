# Creator desk

The dashboard takes its dark surfaces and clear hierarchy from both supplied references. A shortcut rail sits beside two large, full-height tools: private coin AI and the developer terminal. Existing NUCALORIC fonts, artwork, wallet icons and dark/pink palette remain in use. Surfaces use flat colors. Desktop chat text and inputs use 14px type; terminal output uses 13px type.

Manage workspace opens a large native dialog with readable forms. Projects, servers and coins have searchable lists alongside their details. Connections, credits and more tools use the same drawer. Opening it preserves both tool nodes and active requests. Escape or the close button returns to the workbench. Selecting a server or coin returns to its tool; project selection keeps its editable brief open. The project manager edits the brief, adds milestones, tracks completion and archives projects. The Archived filter restores a project. Projects and milestones are saved in browser storage on this device; Export and Import use the existing validated backup format. They are separate from authenticated server and coin records.

Server and coin lists contain the signed-in account’s native records. Selecting a server uses the existing owner-checked terminal. Selecting a coin uses its existing private AI workspace, models, saved context and knowledge. Coin and model selectors also remain available directly in chat. The drawer preserves the authentication gate for private coin controls. Save to knowledge opens the moved editor before focusing it. Connections, payout plans, credits, Jupiter tools, fleet status and the selected server plan remain available as full-size management sections.

Ctrl/Command K opens the searchable action palette. Arrow keys select an action, Enter opens it, and Escape closes it. Outside text fields, / opens and focuses project search. Alt 1 opens the terminal, Alt 2 focuses AI, and Alt 3 opens the project manager. Panel arrow buttons give AI or terminal more room while leaving the other tool visible.

Panels arrive once with staggered motion; drawer openings, selections and disclosures provide short feedback. A nine-pixel animation follows the NUCALORIC wordmark’s rhythm. Terminal server refresh, commands, model setup, AI submission and pending AI replies expose actual request phases. Coin chat indicates loading, submission, pending inference and reconnection. Waiting shows elapsed time rather than simulated progress. Completion hides the indicator; errors stop its animation and show the failure. Timers for elapsed time run only while a request is active. Terminal server selection is blocked during an active command or refresh to preserve its transcript. Motion can be paused, and the operating system’s reduced-motion preference is respected. Other pages retain existing shared styling.

At desktop widths the tools share the available width and height, with independently scrolling transcripts. Short desktop screens can scroll rather than compress the controls. Tablet and phone layouts stack spacious tools without introducing dashboard pages or tabs. The management drawer becomes nearly full-screen on phones, with its list and details in one scrollable surface.
