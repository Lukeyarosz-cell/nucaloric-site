# Transfers, market details and workspace surfaces

The [supplied file-card reference](https://www.pinterest.com/pin/588986457572786016/) informs the glass transfer dialog: a folded file badge, blue edge light, inset progress and installation prerequisites. The implementation uses CSS and native controls; the reference image is kept in the private design review folder.

The shared dialog covers owned server-app installation, website HTML selection/publication, GitHub static publication, coin artwork, coin-plan/project-library imports and Jupiter Studio artwork preparation. Prerequisites run before mutation. Server-app installation re-reads actual disk usage and confirms the installed package's integrity. File reads report actual byte progress; server operations use an indeterminate bar until the request completes. Hiding feedback does not cancel a request. Errors remain visible, and completion returns to the original control. No extra confirmation is added to an action the user already selected; existing GitHub and wallet approvals remain.

Explore has one accessible quick-look inspector. It displays identity/artwork, the exact mint/pool, price, liquidity, volume, market cap, FDV, buys/sells, pool creation and provider links. The inspector retains its chart when a coin is saved and uses the complete current observation rather than only filtered cards. Refresh failures clear the observation. The duplicate empty inspector is removed.

Quick-look and the full coin profile load historical OHLCV from GeckoTerminal for the exact Solana pool and token address. Native candles and volume support 15-minute, hourly and daily intervals, refresh, keyboard descriptions and an external DEX Screener link. Token metadata must match. Requests are bounded, old requests are cancelled and successful observations are cached for one minute. Empty, unreadable, timed-out or rate-limited responses show a useful unavailable state while preserving independently loaded pool details. No prices are inferred from percentage changes. Public profiles show pool details in the side panel; local plans retain their revenue planning controls.

Launch now groups local intelligence and existing Jupiter controls in a responsive glass workbench. Provider/account configuration still determines availability. Pricing replaces the old service ribbon with an etched NUCALORIC Paymenter server and six connected routes: account, wallet credits, own hardware, hosted websites, terminal and local intelligence, plus Basic/Full and the tool store. Prices remain $1.50 Basic and $2 Full per calendar month; Reason/Code remain $0.50 per 1,000 processed tokens. Diagram cables follow the actual controls at each viewport size. They convey navigation, not live payment activity.

Hosting telemetry is a smaller glass panel with compact counters, allocation banks and a two-column allocation/network layout on desktop. Mobile stacks the same measurements. Existing freshness, unknown capacity, stopped allocations, observed rates and model-runtime semantics are retained.

Validation uses live public pool/candle responses and isolated local server files. Installation, quota races, invalid/valid imports, website publishing with installed apps, chart failure, saved-chart preservation, focus restoration, stale telemetry and responsive layouts are checked. No customer server or wallet was used. The native Pi release includes the earlier pending telemetry/store backend package and remains staged until the existing Pi admin session is available.

Primary data contracts: [DEX Screener API](https://docs.dexscreener.com/api/reference) and [GeckoTerminal/CoinGecko pool OHLCV](https://docs.coingecko.com/reference/pool-ohlcv-contract-address).
